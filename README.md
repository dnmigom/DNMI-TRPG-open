# 캐릭터 시트 보관함

GitHub API로 TRPG 캐릭터와 캐릭터 시트를 보관하고 열람하는 사이트예요.

- 홈은 **캐릭터 목록**이에요. 캐릭터 하나가 여러 룰의 시트를 가질 수 있어요.
- 캐릭터 화면은 **왼쪽에 인장**(두상·흉상·반신·전신 탭), **오른쪽에 룰 시트**(룰마다 탭)가 있어요. 인장 크기가 달라도 시트 모양은 바뀌지 않아요.
- 모든 데이터는 **비공개 저장소**에 저장돼서 토큰이 없으면 아무도 못 봐요.
- **공유 허용**은 룰 시트마다 따로 켜요. 그 시트 한 장과 인장만 비밀 Gist로 올라가고 링크가 생겨요. **공유 중지**를 누르면 Gist가 삭제돼서 링크가 바로 막혀요.
- 공유 중인 시트는 **저장할 때 공유본도 자동으로 갱신**돼요.
- 룰마다 틀(템플릿)을 사이트 안에서 직접 만들 수 있고, 화면 디자인은 모든 룰이 같아요(룰마다 강조색만 바뀌어요).

## 저장소 두 개

| 저장소 | 공개 여부 | 들어가는 것 |
|---|---|---|
| 사이트 저장소 (예: `trpg-sheet-site`) | **공개** | `site/` 폴더 안의 파일 4개 |
| 데이터 저장소 (예: `trpg-data`) | **비공개** | `templates/`(룰 틀 보관함), `datasets/`(데이터 보관함), `characters/`(캐릭터와 시트), `images/`(인장). 사이트가 알아서 만들어요 |

사이트 코드에는 시트 내용이 전혀 없어서 공개해도 괜찮아요. (무료 플랜에서는 비공개 저장소로 GitHub Pages를 열 수 없어서 이렇게 나눠요.)

## 설치 순서

1. **데이터 저장소 만들기**: GitHub에서 새 저장소를 **Private**으로 만들어요. (README 하나만 있어도 돼요. 예시 룰 틀이 필요하면 `templates` 폴더에 `data/templates/example.json`을 올려요.)
2. **사이트 저장소 만들기**: 새 저장소를 **Public**으로 만들고 `site` 폴더 안의 파일 6개(`index.html`, `style.css`, `engine.js`, `app.js`, `editor.js`, `data.js`)를 맨 위(루트)에 올려요.
3. **Pages 켜기**: 사이트 저장소 → Settings → Pages → Branch를 `main` / `(root)`로 두고 Save를 눌러요. 잠시 뒤 `https://내아이디.github.io/사이트저장소/` 주소가 생겨요.
4. **토큰 만들기**: GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Repository access: **Only select repositories** → 데이터 저장소 **하나만** 선택
   - Repository permissions → **Contents: Read and write**
   - Account permissions → **Gists: Read and write**
   - 만료일은 원하는 만큼 정해요. 만료되면 새로 만들어서 설정 화면에 다시 넣으면 돼요.
5. 사이트 주소로 들어가서 **사용자명 / 데이터 저장소 이름 / 토큰**을 넣으면 끝이에요.

> 토큰은 그 브라우저에만 저장돼요. 다른 기기에서는 한 번 더 입력해야 해요. 남과 같이 쓰는 컴퓨터에서는 설정 화면의 **이 기기에서 로그아웃**을 눌러 주세요.

## 읽기 모드와 편집 모드

캐릭터 화면 오른쪽 위의 **읽기 / 편집** 버튼으로 바꿔요. 마지막에 고른 모드를 그 브라우저가 기억해요. 처음에는 읽기 모드로 열려요.

- **읽기 모드**: 시트가 글처럼 보이고, 값을 실수로 고칠 수 없어요. 색 막대, 인장 올리기 버튼, 룰 시트 추가·삭제, 캐릭터 삭제 버튼도 숨겨져요. 빈 칸은 "—"로 보여요. 공유 링크와 코코포리아로 복사는 읽기 모드에서도 쓸 수 있어요.
- **편집 모드**: 지금까지처럼 모든 것을 고칠 수 있어요.
- 편집하다가 저장하지 않고 읽기 모드로 바꿔도 고친 내용은 남아 있어요. 이때는 저장 버튼이 계속 보여요.

## 캐릭터와 인장

- 홈에서 **+ 새 캐릭터** → 캐릭터 화면에서 **+ 룰 시트 추가**로 그 캐릭터가 쓸 룰을 골라요. 한 캐릭터에 룰마다 시트 한 장씩 가질 수 있어요.
- 룰 탭을 오가도 입력한 값은 사라지지 않아요. **저장**을 누르면 캐릭터 전체(이름, 인장, 모든 룰 시트)가 한 번에 저장돼요. (Ctrl+S / ⌘S도 돼요)
- 인장은 두상·흉상·반신·전신 탭마다 하나씩 넣을 수 있어요. 있는 것만 넣으면 되고, 공유 화면에서는 이미지가 있는 탭만 보여요.
  - **파일 올리기**: 데이터 저장소의 `images/`에 저장돼요(비공개). 가장 긴 쪽이 1600px보다 크면 자동으로 줄여요. GIF는 그대로 올라가요(4MB까지).
  - **주소로 넣기**: 바깥에 올려 둔 이미지 주소(https://…)를 써요. 그 사이트가 막으면 안 보일 수 있어요.
- 홈의 캐릭터 카드에는 두상 → 흉상 → 반신 → 전신 순서로 처음 있는 이미지가 보여요.
- 예전 방식(시트 하나 = 캐릭터 하나)으로 저장된 시트가 있으면 홈에 **캐릭터로 옮기기** 버튼이 나와요. 이름이 같은 시트는 한 캐릭터로 합쳐지고, 공유 링크는 그대로 유지돼요.

## 캐릭터 색과 꾸미기

캐릭터 화면의 이름 아래 색 막대에서 정해요.

- **머리 / 눈 1 / 눈 2**: 먼셀 표색계 10색(빨강·주황·노랑·연두·초록·청록·파랑·남색·보라·자주)에 **흰색·회색·검은색**을 더한 13가지 중에서 골라요. (예전에 "무채색"으로 골라 둔 캐릭터는 회색으로 바뀌어요) 오드아이나 한쪽 눈에 두 색이 있으면 눈 2까지, 아니면 눈 1만 골라도 돼요.
- **강조색**: 버튼·제목 막대·계산 칸 색이에요. "룰 기본"이면 룰 틀의 색을, 머리/눈 1/눈 2를 고르면 그 색을 써요. 흰 글씨가 잘 보이도록 조금 진하게 바꿔서 써요.
- **배경색**: 고른 색의 파스텔 톤으로 화면 배경과 입력칸이 바뀌어요. 홈의 캐릭터 카드 배경에도 쓰여요.
- 공유 화면에도 같은 색과 꾸미기가 적용돼요. 어두운 화면(다크 모드)에서는 같은 색의 어두운 톤으로 바뀌어요.

### 홈에서 모아 보기 (필터)

- **룰 / 머리색 / 눈 색** 버튼을 눌러 골라요. 눈 색은 눈 1·눈 2 중 하나라도 맞으면 보여요.
- 같은 줄 안에서 여러 개를 고르면 "하나라도 맞는" 캐릭터, 줄끼리는 "모두 맞는" 캐릭터가 보여요. (예: 머리 노랑 + 눈 빨강·파랑 → 머리가 노랑이면서 눈에 빨강이나 파랑이 있는 캐릭터)
- 버튼 옆 숫자는 그 버튼을 눌렀을 때 보일 캐릭터 수예요. 캐릭터가 하나도 없는 색은 나오지 않아요.
- 캐릭터를 보고 돌아와도 고른 필터는 유지돼요.

## 공유할 때 알아 둘 점

- 공유 링크는 `사이트주소/?share=…` 모양이에요. 받는 사람은 로그인 없이 **읽기 전용**으로 봐요.
- 비밀 Gist는 검색이나 목록에 나오지 않지만, **링크를 가진 사람은 누구나** 볼 수 있어요. 링크가 퍼졌다면 공유 중지 후 다시 공유하면 새 링크가 생겨요.
- 공유본에는 그 룰의 틀(template)과 **인장**도 함께 들어가요. 받는 사람이 비공개 저장소를 볼 필요가 없게 하려는 거예요.
- 공유는 룰 시트마다 따로예요. 같은 캐릭터라도 공유를 켠 룰의 시트만 보여요.

## 룰 틀(템플릿) 만들기

### 사이트에서 직접 만들기 (추천)

위쪽 메뉴의 **룰 틀 보관함** → **+ 새 룰 틀**을 누르세요. 비슷한 룰이 이미 있으면 그 룰의 **복제**에서 시작하는 게 편해요.

- **칸 묶음**은 능력치·자원처럼 칸이 모인 카드이고, **표**는 기능·소지품처럼 줄을 늘릴 수 있는 카드예요.
- 칸마다 이름을 쓰고 종류(글자 / 숫자 / 긴 글 / 체크 / 선택 목록 / 그림 주소 / **자동 계산**)를 고르면 돼요.
- 오른쪽 **미리보기**에 실제 시트가 바로 그려져요. 값을 넣어 보면서 계산이 맞는지 확인할 수 있어요. (미리보기에 넣은 값은 저장되지 않아요)
- 저장하면 `templates/룰이름.json`으로 데이터 저장소에 들어가요.

**수식을 엑셀처럼 만드는 법**

1. 종류를 **자동 계산**으로 바꾸면 `fx` 수식 칸이 생겨요.
2. 수식 칸을 누르면 아래에 도우미가 열려요.
   - **함수** 버튼: `내림( )`처럼 괄호까지 들어가고, 커서가 괄호 안에 놓여요. 글자를 드래그로 선택한 채 누르면 그 부분을 괄호로 감싸요.
   - **기호** 버튼: + − × ÷ 괄호와 비교 기호
   - **칸 / 같은 줄 / 표** 버튼: 다른 칸의 이름을 넣어요. 표는 "열 합계"와 "줄 수"를 넣을 수 있어요.
3. 수식을 쓰는 중에 **오른쪽 미리보기의 칸을 클릭**해도 그 칸 이름이 들어가요. (엑셀에서 셀을 클릭하는 것처럼요)
4. 도우미 맨 위에 `✓ 미리보기 값: 3`처럼 결과가 바로 나오고, 잘못되면 `⚠` 표시와 이유가 나와요.

**칸 접어 두기 (계산에만 쓰고 겉으로는 숨기기)**

- 칸 오른쪽의 **👁** 버튼을 누르면 🙈로 바뀌면서 그 칸이 **접힌 칸**이 돼요. 다시 누르면 원래대로 보여요.
- 예: `합계 = a + b`일 때 a와 b를 접어 두면, 시트에는 합계만 보여요.
- 편집 모드에서는 칸 묶음 아래 **숨긴 칸 N개 보기**를 눌러 펼친 뒤 값을 넣어요. 읽기 모드와 공유 화면에서는 아예 안 보여요.
- 접힌 칸도 수식에서는 그대로 쓸 수 있어요. 칸 묶음의 칸이 모두 접혀 있으면 읽기 모드에서는 그 카드 자체가 안 보여요.

**칸 복제와 옮기기**

- **⧉** 버튼을 누르면 그 칸이 바로 아래에 "○○ 사본"으로 복제돼요. 수식도 같이 복사되고, 붙인 숫자의 수식 안에 있는 자기 이름은 새 이름으로 바뀌어요. 표의 열도 같은 버튼으로 복제할 수 있어요.
- 칸 왼쪽의 **⠿** 손잡이를 누른 채로, 또는 칸의 빈 곳을 **꾹 누른 채로** 끌면 칸을 옮길 수 있어요. 다른 칸 묶음으로도 옮길 수 있고, 놓일 자리는 파란 줄로 보여요. 화면 위·아래 끝에 대고 있으면 자동으로 스크롤돼요.
- 휴대폰에서는 화면 스크롤과 헷갈리지 않도록 **⠿ 손잡이로만** 끌 수 있어요.
- 칸을 옮겨도 캐릭터 시트에 넣어 둔 값은 그대로예요.

**한 칸에 숫자 여러 개 (예: 근력 `50 / 25 / 10`)**

1. 종류가 **숫자**나 **자동 계산**인 칸에서 **+ 이 칸에 숫자 더 붙이기**를 눌러요.
2. 붙인 숫자마다 이름(예: 절반, 1/5)을 쓰고, **숫자**(직접 입력)나 **자동 계산**(수식)을 골라요. 처음 붙이면 `내림(첫숫자 / 2)` 수식이 미리 들어가 있어요.
3. 필요하면 **첫 숫자 이름**(예: 보통)과 **숫자 사이 기호**(기본 `/`)도 정해요.
4. 붙인 숫자도 각자 "수식에서 부르는 이름"이 있어서 다른 수식에서 쓸 수 있어요. (예: `근력절반 + 2`) 칸 이름만 쓰면 첫 숫자를 뜻해요.
- 코코포리아 자동 설정에서는 `50/25/10`처럼 한 파라미터로 보내요.

**칸 이름과 "수식에서 부르는 이름"**

- 새로 만든 칸은 이름을 쓰면 수식용 이름이 자동으로 정해져요. (띄어쓰기는 빠져요. 예: `근력 보정` → `근력보정`)
- **더보기**에서 수식용 이름을 직접 바꿀 수 있어요. 바꾸면 그 이름을 쓰던 수식도 자동으로 고쳐져요.
- 단, 이미 시트가 있는 룰에서 수식용 이름을 바꾸면 기존 시트에서는 그 칸의 값이 비어 보여요. 보이는 이름만 바꾸는 건 언제든 괜찮아요.
- 그 룰을 쓰는 시트가 남아 있으면 룰 틀을 삭제할 수 없어요.

**고친 룰 틀은 바로 반영돼요**

- 룰 틀을 저장하면 그 틀을 쓰는 모든 캐릭터 시트에 바로 반영돼요. 새로 추가한 칸은 기존 캐릭터에도 바로 생기고, "처음 값"이 있으면 그 값으로 채워져요.
- 공유 중인 시트의 공유본도 저장할 때 자동으로 새로 올라가요.
- 어떤 캐릭터라도 **값을 넣어 둔 칸·열·표**는 지우거나, 수식 이름을 바꾸거나, "자동 계산"으로 바꿀 수 없게 막혀 있어요. 꼭 바꿔야 하면 그 캐릭터 시트에서 값을 지우고 저장한 뒤 바꾸면 돼요. 보이는 이름(라벨)과 순서는 언제든 바꿀 수 있어요.

### 직접 고칠 때 참고

템플릿 맨 위:

```json
{ "rule": "룰 이름", "description": "짧은 설명", "accent": "#7c5cff", "sections": [ … ] }
```

**묶음(section)**: 카드 하나예요.

| 키 | 뜻 |
|---|---|
| `title` | 카드 제목 |
| `layout` | `"grid"`(칸을 가로로 나열, 기본값) / `"stack"`(한 줄에 하나씩) |
| `wide` | `true`면 카드를 가로 전체로 넓혀요 |
| `fields` | 칸 목록 |
| `type: "list"` + `id` + `columns` | 줄을 추가할 수 있는 표(기능, 소지품 등)예요. `defaultRows`로 처음 줄을 미리 채울 수 있어요 |

**칸(field)**:

| 키 | 뜻 |
|---|---|
| `id` | 수식에서 부를 이름이에요. **띄어쓰기 없이**, 한글 가능. 시트 안에서 겹치면 안 돼요 |
| `label` | 화면에 보이는 이름 |
| `type` | `text`, `number`, `textarea`(긴 글), `checkbox`, `select`(+`options`), `image`(그림 주소 — 인장은 왼쪽 인장 칸을 쓰는 게 좋아요) |
| `formula` | 이게 있으면 자동 계산 칸이 돼요 (`type` 불필요) |
| `default` | 새 시트를 만들 때 처음 값 |
| `max` | 숫자 칸 옆에 `/ 최대값`을 보여 줘요. 칸 id나 수식을 써요 |
| `hint` | 칸 아래 작은 설명 |
| `wide` | 칸을 가로 전체로 |

### 수식에 쓸 수 있는 것

- 칸 id, 숫자, `+ - * / %`, 괄호
- 비교: `>` `<` `>=` `<=` `=` `!=` → 맞으면 1, 틀리면 0
- 체크박스는 체크하면 1, 아니면 0이에요

| 함수 (한국어 / 영어) | 예시 |
|---|---|
| `내림` / `floor` | `내림((근력 - 10) / 2)` |
| `올림` / `ceil` | `올림(레벨 / 4)` |
| `반올림` / `round` | `반올림(체력 / 3)`, 소수 첫째 자리까지: `반올림(x, 1)` |
| `버림` / `trunc` | 0 쪽으로 자르기 |
| `최소` / `min`, `최대` / `max` | `최대(근력, 민첩)` |
| `합계` / `sum` | `합계(근력, 민첩, 정신)` |
| `범위` / `clamp` | `범위(x, 0, 100)` → 0~100 사이로 |
| `만약` / `if` | `만약(부상, -2, 0)` → 부상이면 -2, 아니면 0 |
| `목록합계` / `total` | `목록합계("소지품", "무게")` → 표의 한 열을 모두 더하기 |
| `개수` / `count` | `개수("소지품")` → 표의 줄 수 |

표의 열 수식에서는 같은 줄의 열 id를 쓸 수 있고, 시트의 다른 칸도 쓸 수 있어요. (예: `기본 + 투자 + 만약(부상, -2, 0)`)

수식에 문제가 있으면 그 칸에 **⚠**가 뜨고, 마우스를 올리면 이유가 나와요.

### 주의

- 이미 만든 시트가 있는 룰에서 칸의 `id`를 바꾸면 그 칸의 기존 값이 안 보이게 돼요. `label`(보이는 이름)은 자유롭게 바꿔도 괜찮아요.
- 칸을 새로 추가하는 건 언제든 괜찮아요. 기존 시트에서는 빈칸으로 나와요.

## 데이터 보관함

스킬·아이템·주문처럼 **여러 캐릭터가 같이 쓰는 데이터**를 룰별로 모아 두는 곳이에요. 위쪽 메뉴의 **데이터 보관함** → **+ 새 데이터**.

1. **데이터 이름**(예: 스킬, 아츠, 주문)과 **룰**을 정해요. 어느 룰에도 속하지 않으면 "공용"으로 둬요.
2. **항목 구성**에서 데이터마다 들어갈 칸을 마음대로 정해요. 예: `이름 / 사용 횟수 / 효과 / 해설`, 또는 `이름 / 개요`. 종류는 글자·숫자·긴 글이에요.
   - **첫 번째 항목이 "찾기 이름"**이에요. 룰 틀과 시트에서 이 이름으로 데이터를 찾아요.
3. 오른쪽 **데이터** 표에 한 줄씩 넣거나, **표 붙여넣기**로 엑셀·구글 시트에서 복사한 표를 한 번에 넣어요. 첫 줄이 항목 이름이면 자동으로 건너뛰고, 같은 이름이 이미 있으면 새 내용으로 바뀌어요.

### 룰 틀의 표에 연결하기

1. 룰 틀 편집기에서 표(예: "스킬" 표)를 만들고 **데이터 보관함 연결**에서 데이터를 골라요.
2. **불러올 항목**에서 원하는 것만 체크해요. (예: 효과·사용 횟수만 체크하고 해설은 빼기) 체크한 항목이 표의 열로 생겨요. 열 이름은 나중에 바꿔도 돼요.
3. 시트에서 그 표의 이름 칸에 스킬 이름을 입력하면(목록에서 골라도 돼요) 체크한 항목이 자동으로 채워져요. 룰 틀의 "처음부터 들어 있을 줄"에서도 똑같이 쓸 수 있어요.
4. 데이터 보관함에서 내용을 고치면, 그 데이터를 불러온 모든 시트와 공유본에 바로 반영돼요.

- 데이터에 없는 이름을 입력하면 나머지 칸을 직접 적을 수 있어요. (그 룰에만 있는 특별한 스킬 등)
- 룰 틀에 연결된 데이터 항목은 지우거나 이름을 바꿀 수 없어요. 연결된 데이터 자체도 삭제할 수 없어요. 룰 틀에서 연결을 먼저 풀어 주세요.

## 코코포리아 연동

시트 화면 위쪽의 **코코포리아로 복사**를 누르면 그 캐릭터의 지금 값이 계산된 상태로 복사돼요. 코코포리아 방 화면에서 **붙여넣기(Ctrl+V / ⌘V)** 하면 캐릭터 말이 생겨요. 공유 링크로 받은 사람도 같은 버튼으로 복사할 수 있어요.

- 저장하지 않은 수정 사항도 지금 화면에 보이는 값으로 복사돼요.
- 공유 중인 시트는 캐릭터의 "참조 URL"에 공유 링크가 들어가요.
- 아이콘 이미지는 코코포리아 쪽 제한 때문에 보낼 수 없어요. 붙여넣은 뒤 코코포리아에서 직접 넣어 주세요.

### 무엇을 어디로 보낼지 정하기 (룰 틀 편집기 맨 아래 "코코포리아 연동")

아무것도 정하지 않으면 **자동 설정**으로 보내요. 최대값이 있는 숫자 칸은 상태(막대)로, 나머지 숫자·자동 계산 칸은 파라미터로 가요. **직접 설정하기**를 누르면 자동 설정을 출발점으로 고칠 수 있어요.

| 항목 | 코코포리아에서 | 쓰는 법 |
|---|---|---|
| 상태 | HP·MP 같은 막대 | 현재 값과 최대 값을 **수식**으로 (예: `체력`, `최대체력`) |
| 파라미터 | "이름: 값" 목록 | 글 안에 `{칸이름}`으로 값 넣기 (예: `{근력}`) |
| 이니셔티브 | 행동 순서 | **수식** (예: `민첩`) |
| 채팅 팔레트 | 채팅 팔레트 | 한 줄에 하나씩, `{ }` 안에 칸 이름이나 수식 (예: `1d100<={근력 * 5} 근력 판정`) |
| 표 줄마다 반복 | 채팅 팔레트에 이어 붙음 | 기능 표의 줄마다 한 줄씩 자동 생성 (예: `CC<={합계} 【{이름}】`) |
| 메모 | 캐릭터 메모 | `{직업}`, `{배경}`처럼 글 칸도 넣을 수 있어요 |

- `{#이름}`은 캐릭터 이름이에요.
- 글 칸(글자·긴 글·선택 목록)은 적힌 글 그대로, 숫자·자동 계산 칸은 계산된 숫자로 들어가요.
- 입력칸을 누르면 아래에 칸 이름 버튼이 나와요. 눌러서 넣으면 돼요.
- 다이스 명령어(`CC<=`, `CCB<=`, `1d100<=` 등)는 룰마다 달라요. 코코포리아에서 그 룰의 다이스봇 사용법을 확인해 주세요.
- 편집기 맨 아래 **보내질 데이터 미리보기**에서 결과를 바로 확인할 수 있어요.
